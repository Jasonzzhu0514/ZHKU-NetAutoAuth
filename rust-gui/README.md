# Windows 桌面客户端

白云校区校园网自动认证客户端，使用 Rust 和 egui，支持状态查询、认证、注销与掉线自动重连。

在仓库根目录运行：

```powershell
cargo run --manifest-path rust-gui/Cargo.toml
```

首次运行需要下载依赖并编译，之后启动会更快。

打开后自动查询所在区域和认证状态。填写账号密码后，可以点击「立即认证」，或开启「自动守护」。守护通常每 10 秒检查一次，异常时逐步延长到最多 300 秒；状态不明时不会提交认证。账号密码输入区在守护期间锁定，停止守护后即可修改。

通过窗口标题栏最小化可保持运行，关闭窗口会退出。当前未提供系统托盘或开机启动。账号框右侧的下拉箭头可选择已保存账号，密码框右侧的眼睛图标可切换显示和隐藏密码。填写账号和密码后可开启自动守护；查询进行中也可以开启，当前请求结束后会进入守护。

勾选「记住密码」后，下次打开会自动填回账号密码。勾选「自动登录」会同时开启记住密码，并在下次打开时自动认证、启动掉线守护；自动登录并不代表开机启动。取消记住密码会清除磁盘中保存的密码并关闭自动登录，本次窗口中的密码仍可用于手动认证。未勾选记住密码时，只保存账号和选项。

Rust 版配置使用当前 Windows 用户的 DPAPI 加密，保存在 `%LOCALAPPDATA%\ZHKU-NetAutoAuth\rust-gui\credentials.dat`，不会读取或修改 Python 版已保存的凭据。账号下拉列表中的 × 可删除对应的 Rust 版配置并清空当前输入，不会注销校园网连接；守护时请先停止守护再修改或删除账号。

「注销连接」会先停止自动守护、关闭下次启动自动登录，再注销当前校园网连接，复查确认离线后显示结果。本次输入的账号密码和记住密码选项仍会保留，需要重新连接时可以点击「立即认证」或重新开启守护。

窗口采用浅灰背景与白色卡片，默认约 920 × 760。连接控制和账号配置按 40/60 分栏，较窄窗口会改为上下排列；窗口高度不足时可滚动页面访问所有控件。

日志默认收起，点击底部「运行日志」展开。日志区域随窗口增高而扩展，内容独立滚动，支持选择复制、仅看异常和清空记录。日志按时间、级别、内容排列，完整保留本次运行的请求路径、HTTP 状态、耗时、原始响应和错误详情，密码等敏感内容会脱敏。日志只保存在内存中，时间表示程序启动后的运行时长。

办公区支持实际认证。宿舍区仅识别区域，暂未适配认证。

运行单元测试：

```powershell
cargo test --manifest-path rust-gui/Cargo.toml
```
