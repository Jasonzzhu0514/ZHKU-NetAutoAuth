# ZHKU-NetAutoAuth

每次连校园网，都要打开浏览器、输入学号和密码？**ZHKU-NetAutoAuth** 为仲恺农业工程学院**白云校区**同学提供自动认证：保存一次账号密码，开启守护，就能在认证掉线后自动重新登录，减少重复操作。

## 适用范围

- **系统**：Windows 10 / 11，64 位。
- **校区**：白云校区。
- **办公区**：支持立即认证和自动重认证。
- **宿舍区**：可以识别所在区域，暂不支持认证，后续适配。

## 快速开始

版本发布后，在本仓库的 **Releases** 页面下载附件中的 **ZHKU-NetAutoAuth-v版本号-windows-x64.zip**，解压后双击 **ZHKU-NetAutoAuth.exe**。无需安装 Python，也无需安装其他依赖。

使用前，请先通过网线或 Wi-Fi 接入校园网。程序打开后会显示所在区域。

### 第一次使用

1. 选择 **2 配置账号密码**。
2. 进入 **1 新增或修改配置**，选择 **自动检测**。
3. 输入自己的校园网账号和密码。密码输入时不会显示字符，正常输入后按回车即可。
4. 返回主菜单，选择 **3 立即认证**。
5. 看到“已通过校园网认证”后，选择 **4 持续守护**，保持窗口打开即可。

以后打开程序，直接选择 **4 持续守护**，无需重复输入账号密码。

## 菜单说明

| 菜单 | 用途 |
| --- | --- |
| **1 查看认证状态** | 查看是否已认证，以及当前账号和网络信息 |
| **2 配置账号密码** | 新增、修改账号密码，或删除已保存的凭据 |
| **3 立即认证** | 立即尝试登录校园网 |
| **4 持续守护** | 保持运行，在认证掉线后自动重新登录 |
| **0 退出** | 关闭程序 |

守护期间按 **Ctrl+C** 返回主菜单。关闭窗口会停止守护，不会主动注销当前校园网连接。

## 修改或删除账号密码

修改密码、换账号时，进入 **2 配置账号密码 → 1 新增或修改配置**，重新填写即可。

不再使用或希望清除保存的账号时，进入 **2 配置账号密码 → 2 删除已保存凭据**，输入 **y** 确认。程序会一并清除当前 Windows 用户保存的旧版凭据。删除后，下次自动认证需要重新配置。

## 隐私

账号密码加密保存在本机，供校园网认证使用，不会随程序发布或上传到项目仓库。密码输入时不会显示，使用自己的 Windows 用户即可读取保存的配置；换电脑或 Windows 用户后需要重新填写。

程序会显示在线账号及网络信息。向他人分享截图时，请遮挡账号、IP、MAC 等个人信息。

## 常见问题

**没有安装 Python，能用吗？**

可以，下载 exe 发布包即可。GitHub 的“Download ZIP”下载的是源码，普通用户请使用 Releases 中的 Windows 发布包。

**为什么显示“未检测到校园网”？**

先确认已接入白云校区校园网。如果使用了代理或 VPN，可以暂时关闭后重试。

**为什么宿舍区不能登录？**

宿舍区的认证方式正在适配。目前会显示区域信息，暂不提供宿舍区自动认证。

**为什么认证失败？**

检查账号密码，并尝试在浏览器里正常登录。如果浏览器也无法登录，请先处理账号或校园网问题；如果浏览器可以登录，可以重新配置后再试。

**关闭窗口后，还会自动认证吗？**

不会。需要自动重认证时，请保持守护窗口打开。目前尚未提供开机自启或后台常驻功能。
