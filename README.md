# ZHKU-NetAutoAuth

每次连接校园网，都要打开浏览器、输入学号和密码？**ZHKU-NetAutoAuth** 为仲恺农业工程学院**白云校区**同学提供 Windows 自动认证客户端：填写账号密码、开启自动守护，认证掉线后会自动重新登录，也可以驻留系统托盘运行。

## 适用范围

- **系统**：Windows 10 / 11，64 位。
- **校区**：白云校区。
- **办公区**：支持认证、注销和断线自动重认证。
- **宿舍区**：可以识别所在区域，暂不支持认证。

## 下载与使用

Windows 桌面版对应 **v2.x**。在 [Releases](https://github.com/Jasonzzhu0514/ZHKU-NetAutoAuth/releases) 中选择桌面版本，无需安装 Python 或 Rust。

- **安装版（推荐，从 v2.1.0 开始提供）**：下载 `ZHKU-NetAutoAuth-Setup.exe`，按提示安装。默认为当前用户安装，提供开始菜单和卸载入口。
- **便携版**：下载 `ZHKU-NetAutoAuth.exe`，双击运行。

历史 **v1.x** 是命令行版本。如果 Releases 尚无 v2.x，可以按文末的开发说明从源码启动桌面版。GitHub 的“Download ZIP”下载的是源码，普通用户请使用 Release 中的 exe 附件。

使用前，先通过网线或 Wi-Fi 接入校园网。客户端会自动查询所在区域和认证状态。

### 第一次使用

1. 阅读首次启动的后台运行说明，选择关闭窗口时驻留托盘或直接退出。
2. 在「账号配置」中填写校园网账号和密码。
3. 点击「立即认证」，确认网络状态显示「已通过认证」。
4. 开启「自动守护」，需要时关闭窗口驻留托盘。

隐藏窗口不会自动开启守护，请先确认守护开关已打开。

## 功能说明

| 功能 | 用途 |
| --- | --- |
| 刷新状态 | 查询认证状态、所在区域和在线信息 |
| 最近检查 | 显示最近一次网络状态检查完成的本机时间 |
| 认证页面 | 在默认浏览器中打开所在区域的认证页面 |
| 立即认证 | 使用当前填写的账号密码登录校园网 |
| 注销连接 | 停止守护，并注销当前校园网连接 |
| 自动守护 | 保持运行，认证掉线后自动重新认证 |
| 守护检查间隔 | 在设置中自定义 30～3600 秒的检查间隔，默认 30 秒 |
| 运行日志 | 按本机日期时间显示，支持仅看异常、复制和清空 |
| 设置 | 修改关闭窗口行为、守护检查间隔，管理软件更新 |
| 软件更新 | 检查新版本、查看更新说明，确认后下载并安装 |

## 账号与自动登录

- **记住密码**：下次启动自动填回账号密码；取消后清除保存的密码，本次输入仍可用于认证。
- **自动登录**：同时启用记住密码，下次启动自动认证并开启守护。它不代表开机启动。
- **密码显示**：点击密码框右侧的眼睛图标切换显示和隐藏；驻留托盘后会恢复掩码。
- **切换或删除账号**：停止守护后，使用账号框右侧的下拉箭头选择保存的账号，点击账号旁的 × 删除凭据并清空输入。

守护或网络请求期间，账号输入区会暂时锁定。删除凭据不会注销网络连接；「注销连接」会关闭下次启动的自动登录，保留本次输入，方便之后重新认证。

## 后台运行

默认点击窗口 × 会驻留 Windows 系统托盘，已开启的守护会继续运行。双击托盘图标，或使用右键菜单「打开窗口」，即可恢复界面。

托盘右键菜单显示网络和守护状态。「退出程序」会结束客户端、停止守护，不会主动注销校园网连接。需要直接关闭程序时，也可以在左下角「设置」中选择关闭窗口时退出。托盘不可用时，关闭窗口直接退出。

当前未提供开机启动。

## 软件更新

在左下角「设置 → 软件更新」中点击「检查更新」。也可启用「认证联网后自动检查更新」；发现新版本时会提示，不会自动下载或安装。

点击「下载更新」可查看进度，下载完成并校验通过后，点击「安装并重启」确认升级。安装版使用安装包升级，便携版替换原程序文件；更新会保留现有配置，不会注销校园网连接。

升级期间客户端会短暂退出。已记住密码时，正在运行的守护会在重启后恢复；未记住的密码需要重新输入。新版程序无法启动时，更新助手会尝试恢复旧程序。

更新包来自本仓库的 GitHub Releases，经过 SHA-256 完整性校验。网络受限、缺少校验信息或程序目录不可写时，可打开发布页面手动下载。安装包暂未配置 Windows 代码签名。

v2.0.x 没有内置更新功能，需要手动安装或下载一次 v2.1.0，之后才能使用软件内更新。卸载安装版默认保留账号和窗口设置；如需清除，可以在卸载向导中勾选「同时删除账号与设置」。安装版和便携版共用配置，删除后便携版也需要重新配置。静默卸载默认保留配置。

## 隐私

记住密码时，账号密码使用当前 Windows 用户的 DPAPI 加密保存在本机，仅供校园网认证使用，不随程序发布或上传到项目仓库。换电脑或 Windows 用户后需要重新配置。

日志只保存在本次运行的内存中，密码等敏感凭据会脱敏。在线账号、IP、MAC 等网络信息仍可能出现在界面和诊断日志中，分享截图或日志前请遮挡个人信息。托盘提示不显示账号或设备标识。

## 常见问题

**无法确认所在区域或认证状态？**

确认已经接入白云校区校园网。如果使用代理或 VPN，请检查其路由是否影响校园网访问，再点击「刷新状态」。

**浏览器能登录，客户端却认证失败？**

检查账号密码，在「运行日志」页面查看错误提示。反馈问题时请附上版本和脱敏后的异常信息。

**从旧版升级需要重新填写账号吗？**

首次使用桌面版需要重新配置；桌面版与旧命令行版本使用独立配置。已使用 Rust 桌面客户端的用户继续使用原有配置。

## 开发

客户端使用 **Tauri 2 + React + TypeScript + Fluent UI**，认证、凭据加密和自动守护由 Rust 实现。Windows 开发需要 Node.js 22+、Rust stable、MSVC 构建工具及 WebView2 运行时。在仓库根目录执行：

```powershell
npm ci
npm run desktop
```

验证代码：

```powershell
cargo fmt --check
cargo clippy --locked --all-targets -- -D warnings
cargo test --locked
npm run check
npm run test:ui
cargo fmt --manifest-path src-tauri/Cargo.toml --check
cargo clippy --manifest-path src-tauri/Cargo.toml --locked --all-targets -- -D warnings
```

`npm run desktop:build` 构建 Tauri 客户端。前端源代码位于 `frontend/`，桌面接口与托盘位于 `src-tauri/`，共用 Rust 核心位于 `src/`。凭据与窗口设置位于 `%LOCALAPPDATA%\ZHKU-NetAutoAuth\`，旧目录中的配置会自动迁移，已有新配置不会被覆盖。旧副本保留用于版本回退，删除凭据时会一并清理。凭据继续使用 DPAPI 加密，前端不使用浏览器本地存储保存密码。

v2.2.0 起，正式发布流程构建 Tauri 客户端，提供安装包和便携版两个 exe，不额外打包 ZIP。旧 egui 入口暂留在源码中作为回归基线。

## 历史版本
