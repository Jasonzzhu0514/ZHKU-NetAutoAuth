# ZHKU-NetAutoAuth

每次连接校园网，都要打开浏览器、输入学号和密码？**ZHKU-NetAutoAuth** 为仲恺农业工程学院**白云校区**同学提供 Windows 自动认证客户端：填写账号密码、开启自动守护，认证掉线后会自动重新登录，也可以驻留系统托盘运行。

## 适用范围

- **系统**：Windows 10 / 11，64 位。
- **校区**：白云校区。
- **办公区**：支持认证、注销和断线自动重认证。
- **宿舍区**：可以识别所在区域，暂不支持认证。

## 下载与使用

Windows 桌面版从 **v2.0.0** 开始发布。在 [Releases](https://github.com/Jasonzzhu0514/ZHKU-NetAutoAuth/releases) 中选择桌面版本，下载 **ZHKU-NetAutoAuth.exe**，双击即可运行，无需安装 Python 或 Rust。

历史 **v1.x** 是命令行版本。如果 Releases 尚无 v2.x，可以按文末的开发说明从源码启动桌面版。GitHub 的“Download ZIP”下载的是源码，普通用户请使用 Release 中的 exe 附件。

使用前，先通过网线或 Wi-Fi 接入校园网。客户端会自动查询所在区域和认证状态。

### 第一次使用

1. 阅读首次启动的后台运行说明，选择关闭窗口时驻留托盘或直接退出。
2. 在「账号配置」中填写校园网账号和密码。
3. 点击「立即认证」，确认网络状态显示「已通过认证」。
4. 开启「自动守护」，需要时关闭窗口驻留托盘。

隐藏窗口不会自动开启守护，请先确认守护开关已打开。

## 功能说明

| 功能 | 用途 |
| --- | --- |
| 刷新状态 | 查询认证状态、所在区域和在线信息 |
| 立即认证 | 使用当前填写的账号密码登录校园网 |
| 注销连接 | 停止守护，并注销当前校园网连接 |
| 自动守护 | 保持运行，认证掉线后自动重新认证 |
| 运行日志 | 展开诊断信息，支持仅看异常、复制和清空 |
| 设置 | 修改关闭窗口时的行为 |

## 账号与自动登录

- **记住密码**：下次启动自动填回账号密码；取消后清除保存的密码，本次输入仍可用于认证。
- **自动登录**：同时启用记住密码，下次启动自动认证并开启守护。它不代表开机启动。
- **密码显示**：点击密码框右侧的眼睛图标切换显示和隐藏；驻留托盘后会恢复掩码。
- **切换或删除账号**：停止守护后，使用账号框右侧的下拉箭头选择保存的账号，点击账号旁的 × 删除凭据并清空输入。

守护或网络请求期间，账号输入区会暂时锁定。删除凭据不会注销网络连接；「注销连接」会关闭下次启动的自动登录，保留本次输入，方便之后重新认证。

## 后台运行

默认点击窗口 × 会驻留 Windows 系统托盘，已开启的守护会继续运行。双击托盘图标，或使用右键菜单「打开窗口」，即可恢复界面。

托盘右键菜单显示网络和守护状态。「退出程序」会结束客户端、停止守护，不会主动注销校园网连接。需要直接关闭程序时，也可以在右上角「设置」中选择关闭窗口时退出。托盘不可用时，关闭窗口直接退出。

当前未提供开机启动。

## 隐私

记住密码时，账号密码使用当前 Windows 用户的 DPAPI 加密保存在本机，仅供校园网认证使用，不随程序发布或上传到项目仓库。换电脑或 Windows 用户后需要重新配置。

日志只保存在本次运行的内存中，密码等敏感凭据会脱敏。在线账号、IP、MAC 等网络信息仍可能出现在界面和诊断日志中，分享截图或日志前请遮挡个人信息。托盘提示不显示账号或设备标识。

## 常见问题

**无法确认所在区域或认证状态？**

确认已经接入白云校区校园网。如果使用代理或 VPN，请检查其路由是否影响校园网访问，再点击「刷新状态」。

**浏览器能登录，客户端却认证失败？**

检查账号密码，展开「运行日志」查看错误提示。反馈问题时请附上版本和脱敏后的异常信息。

**从旧版升级需要重新填写账号吗？**

首次使用桌面版需要重新配置；桌面版与旧命令行版本使用独立配置。已使用 Rust 桌面客户端的用户继续使用原有配置。

## 开发

源码使用 Rust 和 egui。安装 Rust stable 与 MSVC 构建工具后，在仓库根目录执行：

```powershell
cargo run --locked
```

验证代码：

```powershell
cargo fmt --check
cargo clippy --locked --all-targets -- -D warnings
cargo test --locked
```

Windows 发布构建由 CI 执行，也可使用 `./scripts/build.ps1` 在本地构建。发布 tag 必须与 `Cargo.toml` 中的版本一致，例如 `v2.0.0`。Release 直接提供 exe，不额外打包 ZIP。

## 历史版本

Python 命令行版本可在 v1.x 历史版本中查看和下载。当前源码以 Rust 桌面客户端为主。
